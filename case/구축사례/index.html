Centric AI suite 도입문의

PDF, 사내 DB, CAD 도면, 규정서 등 

형식에 구애받지 않는 모든 데이터를 AI가 즉시 분석하고 통합합니다.

Text-to-SQL의 한계를 넘어선, 제조 특화 데이터 에이전트 (*****​컴퍼니)

제조·생산·열처리 데이터의 고난도 조회 어려움, 데이터 정합성 문제, IT 부서 의존도 해소 필요

도입 전, 현업의 고통(Pain Point)

  • 데이터 접근의 벽: ERP 및 레거시 DB에 저장된 핵심 생산 데이터가 IT 부서 전유물이 되어, 현업의 즉각적인 의사결정을 방해했습니다.

  • 복잡한 쿼리 작성: "최근 5년 수출구분별 수주건수"나 "열처리 OK/NG 품명·업체별 집계"와 같은 고난도 질의를 위해 매번 SQL 코딩이 필요했습니다.

  • 정합성 및 보안 우려: 직접 조회 시 데이터 오류 가능성과 개인정보 유출 리스크가 상존했습니다.

CentricAI Suite의 해결 방안 (Solution)

단순한 Text-to-SQL을 넘어, 제조 환경에 최적화된 하이브리드 스키마 RAG​와 멀티모달(Vision) 에이전트​를 도입했습니다.

  • 🧠 하이브리드 스키마 RAG: 레거시 DB 구조를 AI가 학습하여, 복잡한 관계형 데이터도 정확하게 이해하고 검색합니다.

  • 👁️ 멀티모달(Vision) 질의: ERP 화면 캡처나 이미지 입력만으로 SQL을 자동 생성하는 혁신적인 인터페이스를 제공합니다.

  • 🛠️ 자기치유 엔진(Self-Healing): SQLGlot 기반의 오류 수정 및 재시도 엔진이 작동하여, 실패하는 쿼리를 자동으로 교정하고 성공적인 결과를 도출합니다.

도입 효과 (Impact)

  • 🚀 IT 의존도 0%: 현업 담당자가 IT의 도움 없이도 자연어(평문)로 고난도 데이터를 직접 조회하고 분석합니다.

  • 📊 직관적 시각화: 복잡한 데이터가 ​DataGrid와 ​차트로 즉시 변환되어, 경영 의사결정 속도가 비약적으로 향상되었습니다.

  • 💡 핵심 가치: "자연어 입력 → DataGrid + 차트 출력". 대화하듯 쉽게, 그러나 정확하게 데이터를 다룹니다.

오프라인 공간의 실시간 AI 아바타 (**소나 AI)

오프라인 방문객과 실시간으로 대화하는 AI 안내 서비스 구현

피지컬 AI 레이어(하드웨어)와 소프트웨어 AI 플랫폼 레이어(두뇌)를 분담하여 하나의 완성된 서비스 구축

도입 전, 현업의 고통(Pain Point)

  • 하드웨어와 소프트웨어의 단절: 아바타 렌더링, 음성 인식(STT) 등 하드웨어 기술과 LLM 응답 생성, 지식 기반 답변 등 소프트웨어 기술이 분리되어 있어 통합 관리가 어려웠습니다.

  • 실시간 응답의 한계: 방문객과의 자연스러운 대화를 위해 스트리밍 응답 처리와 실시간 지식 기반 답변이 필요했으나, 기존 시스템에서는 지연 시간이 발생했습니다.

CentricAI Suite의 해결 방안 (Solution)

CentricAI Suite가 피지컬 AI·키오스크·로봇 등 하드웨어 직접 솔루션의 두뇌 역할​을 담당하도록 아키텍처를 설계했습니다.

  • 🧠 두뇌 레이어(소프트웨어 플랫폼):

    1. LLM 응답 생성: Platform - Model Gateway를 통해 효율적인 응답 생성

    2. 지식 기반 응답: 사내 지식 기반을 활용한 정확한 안내

    3. 운영 통제: 전사적 운영 통제 구조 유지

  • 🗣️ 피지컬 AI 레이어 (하드웨어 & UX):

    1. 하드웨어 & UX 설계: 아바타 렌더링 및 립싱크 처리

    2. 음성 처리: STT 수신 및 TTS 출력 처리를 CentricAI 플랫폼 레이어와 연결

도입 효과 (Impact)

  • 🔗 인터페이스 독립성: CentricAI는 어떤 인터페이스든 STT로 입력과 TTS 출력을 플랫폼 레이어에 연결할 수 있어, 확장성이 뛰어납니다.

  • 🚀 기술 기반 축적: 스트리밍 응답 처리, 실시간 지식 기반 답변, 운영 통제 구조가 구현되었으며, 이는 이후 CentricAI의 ​음성 입력(STT/TTS) 기능과 ​회의록 에이전트의 핵심 기반 기술로 활용되었습니다.

  • 💡 핵심 가치: "STT·TTS 기반의 실시간 AI 아바타 구현". 물리적 공간에서도 소프트웨어 AI 플랫폼의 힘을 온전히 발휘합니다.
