Core Features

AI가 만드는 원판 배치의 혁신

수작업으로 몇 시간 걸리던 원판 배치 작업을 AI가 몇 분 안에 처리합니다.

발주서 자동 인식

발주서 이미지나 사진을 올리면 AI가 부품명, 수량, 원판 치수를 자동으로 읽어옵니다. 수동 입력이 필요 없습니다.

형상 자동 검증

AI가 읽은 부품 형상을 도면과 겹쳐 자동으로 검증합니다. 치수 불일치, 모양 어긋남을 빨간색으로 표시해 줍니다.

최적 배치 알고리즘

수천 가지 배치 조합 중 수율을 최대화하는 최적해를 계산합니다. 자투리를 최소화하고 원판당 최대 부품을 배치합니다.

사람-AI 협업 검증

AI가 제안한 모든 결과는 사람이 최종 확인합니다. 불합격 카드에는 어디가 틀렸는지 빨간 상자로 표시해 줍니다.

자투리 원판 분석

이미 사용한 원판의 사진을 올리면 남은 소재를 분석해 추가 배치가 가능합니다. 소재 낭비를 줄입니다.

CAD 파일 즉시 출력

배치가 완료되면 DXF 파일을 즉시 다운로드할 수 있습니다. AutoCAD 2010 형식으로 호환성 문제를 해결했습니다.

Use Cases

어떤 산업에서 활용되나요

원형 소재를 절단하는 모든 공정에서 효과를 발휘합니다.

⚙️ 금속 가공 산업

원판 소재에서 부품 절단 배치를 최적화합니다. 와이어 컷, 플라즈마, 레이저 절단 가공에 바로 활용 가능합니다. 자투리 원판 분석으로 소재 비용을 절감합니다.

와이어 컷 플라즈마 절단 레이저 절단

🔩 금속 부품 제조

볼트, 너트, 와셔 등 표준 부품부터 맞춤형 부품까지 원판 배치 작업을 자동화합니다. 이등변삼각형 등 특수 형상도 진성 꼴로 최적 배치합니다.

표준 부품 맞춤 부품 NC 가공

🏭 판금 가공

두께 1.6T부터 다양한 판재의 원판 배치를 처리합니다. 발주서 한 장으로 DXF 파일을 생성해 가공 준비 시간을 대폭 단축합니다.

판금 용접 부품 도면 자동 생성

📐 설계·생산 통합

도면 읽기 → 형상 검증 → 배치 계산 → DXF 출력까지 전 과정을 AI가 처리합니다. 설계 변경 시 재배치 시간도 최소화합니다.
